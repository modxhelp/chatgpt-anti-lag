# Security Policy

## Данные пользователя

ChatGPT Anti-Lag хранит статические снимки старых сообщений только в IndexedDB текущего браузерного профиля. Userscript не содержит кода отправки данных на сторонние серверы и не запрашивает сетевые разрешения userscript-менеджера.

## Сообщение об уязвимости

Не публикуйте в issue содержимое личных переписок, экспорт IndexedDB, токены, cookies или другие секреты. Опишите воспроизводимый сценарий без пользовательских данных и укажите версию браузера, userscript-менеджера и userscript.

## Поддерживаемая версия

Исправления безопасности выпускаются для последней опубликованной версии.
