# Changelog

Все заметные изменения проекта фиксируются в этом файле.

## 3.0.0 — 2026-07-27

### Архитектура

- Новая схема IndexedDB версии 2 с отдельными хранилищами `chats` и `messages`.
- Одно сообщение хранится одной записью; в метаданных чата остаётся только лёгкий индекс.
- Запись сообщений и метаданных выполняется одной транзакцией.
- Несовместимое хранилище `chatArchives` версии 2.0.0 удаляется при миграции.

### Производительность

- Пакетная архивация и пакетное восстановление.
- Полный HTML архивных сообщений не хранится постоянно в JavaScript-состоянии.
- Используются `content-visibility: auto` и `contain-intrinsic-size: auto 600px` без глобального отключения прокрутки и scroll anchoring.
- Добавлена компенсация позиции прокрутки при изменении DOM.

### Надёжность

- Метаданные архива действительно читаются после перезагрузки.
- Уже сохранённые сообщения удаляются из DOM без повторной записи.
- Дедупликация использует `data-message-id`, а при его отсутствии — отпечаток сообщения.
- Обрабатывается смена ветки ответа с тем же `conversation-turn`.
- DOM-узел удаляется только после успешной фиксации записи или при наличии готовой записи в IndexedDB.
- Добавлены Web Locks и BroadcastChannel для нескольких вкладок.
- Асинхронные результаты предыдущего маршрута отбрасываются через `sessionEpoch`.
- Архивация приостанавливается во время генерации ответа и при раскрытом архиве.

### Хранилище

- Лимит одного чата — 80 МБ.
- Общий программный лимит — 150 МБ.
- До 30 архивов и до 45 дней хранения неактивных архивов.
- Добавлена ручная очистка текущего и всех архивов.

### Интерфейс

- Настройка числа живых пар.
- Отображение количества сообщений и размера архива.
- Порционное восстановление: «Показать», «Ещё», «Скрыть».
- Безопасное выключение с очисткой текущего архива и перезагрузкой страницы.

### Доставка и контроль качества

- Добавлены `@updateURL` и `@downloadURL` для автоматического обновления.
- Добавлены `package.json`, статическая проверка userscript и GitHub Actions.
- Добавлены `.editorconfig`, `.gitattributes` и `.gitignore`.
