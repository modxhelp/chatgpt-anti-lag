# ⚡ ChatGPT Anti-Lag Archive

Локальный userscript для ChatGPT, который разгружает длинные чаты за счёт архивации старых сообщений в IndexedDB и удаления их из DOM до момента, пока они снова не понадобятся.

Скрипт оставляет в DOM только последние сообщения, а более старые:
- сохраняет в IndexedDB браузера;
- удаляет из DOM;
- заменяет одним компактным архивным блоком.

Это делает длинные переписки заметно легче для браузера и уменьшает нагрузку на интерфейс.

## ✨ Что умеет

- оставляет в DOM только последние 3 сообщения;
- архивирует старые сообщения в IndexedDB;
- удаляет архивированные сообщения из DOM;
- показывает компактный блок с количеством скрытых сообщений;
- восстанавливает архив по кнопке «Показать»;
- отображает восстановленные сообщения с плавной анимацией;
- работает локально, без сервера и без API;
- поддерживает `chatgpt.com` и `chat.openai.com`.

## ⚙️ Как это работает

Скрипт не удаляет историю чата на стороне ChatGPT.

Он работает только во фронтенде браузера:

1. Находит сообщения в открытом чате.
2. Оставляет в DOM только последние 3.
3. Старые сообщения сериализует как HTML-снимки.
4. Сохраняет их в IndexedDB.
5. Удаляет их из DOM.
6. Вставляет на страницу компактный архивный блок.
7. По кнопке «Показать» достаёт архив из локального хранилища и вставляет его обратно с анимацией.

## 🖥️ Что видит пользователь

После архивирования в чате появляется компактный блок примерно такого вида:

- скрыто N сообщений
- кнопка **«Показать»**

После нажатия архивированные сообщения возвращаются в интерфейс.

## 📦 Установка

1. Установить Tampermonkey или другой userscript-менеджер
2. Создать новый userscript
3. Вставить код из файла `chatgpt-anti-lag-archive.user.v2.0.0.js`
4. Сохранить
5. Открыть `https://chatgpt.com/`
6. Загрузить длинный чат и проверить работу скрипта

## ✅ Что даёт такой подход

- меньше DOM-узлов в длинных чатах;
- меньше нагрузка на браузер;
- более лёгкая прокрутка;
- меньше тормозов на больших переписках;
- старые сообщения не пропадают, а хранятся локально.

## ⚠️ Важные особенности

- это экспериментальная архивная версия;
- восстановленные старые сообщения показываются как HTML-снимки, а не как исходные React-узлы ChatGPT;
- текст, структура и оформление должны отображаться нормально, но часть мелкой интерактивности у восстановленных сообщений может отличаться от оригинала;
- после изменений интерфейса ChatGPT селекторы и логика могут потребовать обновления;
- IndexedDB хранится локально в браузере, в котором был открыт чат.

## 🔒 Безопасность

Скрипт:

- не отправляет данные на сторонние серверы;
- не использует внешний backend;
- не удаляет переписку с серверов ChatGPT;
- хранит архив только локально в браузере через IndexedDB;
- работает только на страницах ChatGPT.
