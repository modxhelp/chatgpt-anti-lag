# ⚡ ChatGPT Anti-Lag

Лёгкий userscript для ChatGPT, который уменьшает лаги :contentReference[oaicite:1]{index=1}ения или виртуализирует их и оставляет активными только последние несколько.

## ✨ Что умеет

- 3 режима: Авто, Мягкий, Жёсткий
- настройка, сколько последних сообщений оставлять открытыми
- счётчик скрытых / виртуализированных сообщений
- счётчик реально отрендеренных сообщений
- кнопка «Показать всё»
- сворачивание панели
- сохранение настроек в браузере
- поддержка `chatgpt.com` и `chat.openai.com`

## ⚙️ Как работает

Скрипт не удаляет историю на сервере ChatGPT — он меняет только отображение страницы в браузере.

- **Авто** — сам выбирает подходящий режим в зависимости от длины чата
- **Мягкий** — старые сообщения скрываются, когда ты находишься внизу диалога
- **Жёсткий** — сообщения вне экрана заменяются на spacer-блоки той же высоты и возвращаются обратно при прокрутке
- во время генерации ответа жёсткая виртуализация не вмешивается лишний раз
- при переключении между чатами состояние корректно пересчитывается

## 🖥️ Панель управления

В правом нижнем углу страницы отображается небольшая панель:

- **Антилаг** — включить / выключить
- **Режим** — Авто / Мягкий / Жёсткий
- **Оставлять** — сколько последних сообщений держать открытыми
- **Скрыто** — текущее число скрытых или виртуализированных сообщений
- **Рендер** — сколько сообщений сейчас реально отрисовано
- **Показать всё** — вернуть все сообщения и выключить антилаг
- **Свернуть** — уменьшить панель

## 📦 Установка

1. Установить Tampermonkey или другой userscript-менеджер
2. Создать новый userscript
3. Вставить код из `chatgpt-anti-lag.user.js`
4. Сохранить
5. Открыть `https://chatgpt.com/`

## ⚙️ Рекомендуемые настройки

- Для большинства пользователей: **Авто**, **Оставлять 4**
- Для максимальной предсказуемости: **Мягкий**
- Для очень длинных чатов: **Жёсткий**
- Если часто возвращаешься к последним сообщениям: **Оставлять 5–6**

## ⚠️ Ограничения

- Это не серверная оптимизация, а только изменение отображения в браузере
- После обновлений интерфейса ChatGPT может потребоваться доработка селекторов или логики
- Жёсткий режим сильнее вмешивается в DOM, чем мягкий
- Поведение может немного отличаться в зависимости от структуры страницы и длины ответа

## 🔒 Безопасность

Скрипт:

- не отправляет данные на сторонние серверы
- не удаляет историю чатов на сервере ChatGPT
- хранит только локальные настройки в `localStorage`
- работает только на страницах ChatGPT
